🎉 Name Art Generator 🎉

Name Art Generator is a fun and interactive React project that allows users to enter their name, age, job, best friend, and current mood — then generates a personalized card with creative and positive messages.

It was built to practice React fundamentals like useState Hook, handling input values, and conditional rendering.
The design focuses on a colorful, friendly interface with smooth animations and a playful touch.

💻 Technologies Used

React.js

HTML5

CSS3

JavaScript (ES6)
